---
title: "CLI for agents"
description: "Use structured Syntheo CLI output as an agent-friendly MCP fallback."
---

Use the global `--json` flag whenever an agent consumes CLI output.

A successful response contains `schema_version`, `command`, `data`, and optional `pagination`. Read results from `data`. Follow `pagination.next_offset` only when you need another page.

Meeting reads default to the local database. Use `meetings --source cloud` after `syntheo auth login` to read opted-in Cloud snapshots, or `meetings --source auto` to use Cloud only when the local database is absent.

## Resolve meeting context

```bash
syntheo --json meetings list --query "weekly planning" --limit 10
syntheo --json meetings get MEETING_ID
syntheo --json meetings --source cloud list --query "weekly planning" --limit 10
```

Search is case-insensitive across meeting titles and IDs. If several meetings match, ask the user to choose one.

## Read the smallest useful surface

```bash
syntheo --json meetings note MEETING_ID --kind note
syntheo --json meetings note MEETING_ID --kind summary
syntheo --json meetings history MEETING_ID --limit 10 --offset 0
```

Use `meetings get` when participants or action items matter. Use `meetings note` when note content alone is enough.

## Stage an edit

```bash
syntheo --json proposals create --meeting MEETING_ID --kind summary --content "Replacement markdown"
syntheo --json proposals list --meeting MEETING_ID
syntheo --json proposals show PROPOSAL_ID
syntheo --json proposals decline PROPOSAL_ID
```

<Note>
  The create command returns a pending proposal. Do not claim the meeting changed. Open the meeting in the desktop app to apply it, or decline it from the CLI or desktop app. Only pending proposals can be declined.
</Note>

## Transcripts

```bash
syntheo --json meetings transcript MEETING_ID --limit 200 --offset 0
```

Transcript limits are measured in words. A page defaults to 200 words and caps at 500. Stop paging once you have enough evidence.

## Diagnose setup

```bash
syntheo --json doctor
```

The report includes the CLI version, resolved database path, read-only connection status, and schema readiness. When `ready` is false, the command still prints the report to standard output and exits with status 1.

## Exports

Only export a complete meeting when the user explicitly requests a file:

```bash
syntheo meetings export MEETING_ID --format markdown --output meeting.md
syntheo meetings export MEETING_ID --format json --output meeting.json
syntheo meetings --source cloud export MEETING_ID --format json --output meeting.json
```

<Warning>
  Export refuses to replace an existing file. Use `--force` only after the user explicitly approves overwriting that exact path.
</Warning>

See the [CLI reference](/reference/cli) for every option.
