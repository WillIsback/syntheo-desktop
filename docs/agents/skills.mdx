The public Syntheo skill teaches agents a single workflow across Cloud MCP and the local CLI:

1. Prefer local MCP or `syntheo --json meetings --source local list` when the agent can access your database.
2. Use OAuth-connected Cloud MCP when running remotely or when local access is unavailable.
3. Resolve meeting IDs from search results.
4. Fetch meeting detail before transcript text.
5. Keep transcript reads bounded and never access SQLite directly.

## Sources

- Published skill: `https://github.com/WillIsback/syntheo-desktop/tree/main/docs/skill.md`
- Repository package: [`skills/syntheo`](https://github.com/WillIsback/syntheo-desktop/tree/main/skills/syntheo)
- Agent plugin: [`agent-plugins/syntheo`](https://github.com/WillIsback/syntheo-desktop/tree/main/agent-plugins/syntheo)

The published file is self-contained. The repository package adds references for setup, CLI commands, MCP tools, and errors.

## Install the plugin

The `Syntheo` plugin bundles the skill and an optional hosted Cloud MCP connection. [Install the Syntheo CLI](/installation) for local access; no Cloud login or Pro subscription is needed. For remote access, enable **Settings → Developers → Cloud API & Connectors** with Pro access through a personal plan or an eligible paid Pro workspace membership and connect through OAuth.

<Note>
  The repository package is named **Syntheo**. Its optional hosted connection appears as **Syntheo Cloud**.
</Note>

For Claude Code:

```bash
claude plugin marketplace add WillIsback/syntheo-desktop
claude plugin install syntheo@fastrepl
```

For GitHub Copilot CLI:

```bash
copilot plugin marketplace add WillIsback/syntheo-desktop
copilot plugin install syntheo@fastrepl
```

For ChatGPT and Codex, add the repository source, restart the ChatGPT desktop app, then install **Syntheo** from the Fastrepl source in the Plugins Directory:

```bash
codex plugin marketplace add WillIsback/syntheo-desktop \
  --sparse .agents/plugins \
  --sparse agent-plugins/syntheo
```

Use the host's cloud connection control to sign in and approve OAuth. Some MCP hosts prompt on first cloud tool use. No cloud API key is required for OAuth connections. A skill-only installation does not create an account connection.

The Fastrepl plugin includes an optional **Syntheo Cloud** App connection for Codex. Leave it disconnected for local CLI access. Public directory listings have a separate review and release process from the repository marketplace.

Cursor Teams and Enterprise administrators can import `https://github.com/WillIsback/syntheo-desktop` as a team marketplace, then install **Syntheo**.

## Install in an agent

Install it from the documentation site with the skills CLI:

```bash
npx skills add https://github.com/WillIsback/syntheo-desktop/tree/main/docs
```

For a filesystem-based agent, copy the complete `skills/syntheo` directory into that agent's skills directory. Keep the directory name `syntheo` so relative reference links continue to work.

<Note>
  Agent skill locations and installer commands vary by client. Follow your agent's skill installation instructions rather than copying only `SKILL.md`.
</Note>

The contributor skills under `.agents/skills` are internal repository workflows. They are not part of the public Syntheo skill.
