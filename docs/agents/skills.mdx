title: "Compétence Syntheo"
description: "Apprenez à un agent compatible quand et comment utiliser la CLI et le MCP de Syntheo."
---

La compétence (« skill ») Syntheo apprend à un agent une démarche unique :

1. Vérifier l'accès local avec `syntheo --json doctor`, ou utiliser un serveur MCP Syntheo déjà connecté.
2. Retrouver les identifiants de réunion à partir des résultats de recherche.
3. Lire le détail d'une réunion avant sa transcription.
4. Garder les lectures de transcription bornées, sans jamais accéder directement à SQLite.
5. Préparer des propositions de modification plutôt que modifier les réunions.

La compétence n'installe pas la CLI. [Installez-la](/installation) pour que l'agent puisse s'en servir.

## Installer depuis l'application

Ouvrez **Paramètres → Développeurs**. Dans la section « CLI & MCP », la ligne « Compétences de l'agent » propose le menu « Ajoutez une compétence à… » :

- choisissez un agent précis ;
- ou « Installer pour tous les agents » pour tous les agents détectés.

L'application copie la compétence, embarquée dans l'application et donc à la même version qu'elle, dans le dossier de l'agent :

| Agent | Dossier de la compétence |
| --- | --- |
| Claude Code | `~/.claude/skills/syntheo` |
| Codex | `~/.codex/skills/syntheo` |
| Cursor | `~/.cursor/skills/syntheo` |
| OpenCode | `$XDG_CONFIG_HOME/opencode/skills/syntheo` (par défaut `~/.config/opencode/skills/syntheo`) |

Un agent n'apparaît comme détecté que si son dossier de configuration (`~/.claude`, `~/.codex`, `~/.cursor` ou celui d'OpenCode) existe déjà, c'est-à-dire si vous l'avez déjà utilisé sur cette machine. Une coche indique que la compétence est installée. Réinstaller remplace les fichiers par ceux de la version courante de l'application.

## Installer à la main

Pour un autre agent, copiez le dossier complet [`skills/syntheo`](https://github.com/WillIsback/syntheo-desktop/tree/main/skills/syntheo) du dépôt dans le dossier de compétences de cet agent. Gardez le nom de dossier `syntheo` pour que les liens relatifs vers `references/` continuent de fonctionner.

<Note>
  L'emplacement des compétences varie selon les clients. Suivez les instructions de votre agent, et copiez tout le dossier plutôt que le seul fichier `SKILL.md`.
</Note>

## Contenu du paquet

| Fichier | Rôle |
| --- | --- |
| `SKILL.md` | La démarche générale |
| `references/setup.md` | Installation et configuration |
| `references/cli.md` | Commandes de la CLI |
| `references/mcp.md` | Outils et ressources MCP |
| `references/errors.md` | Erreurs et reprise |

Une version autonome de `SKILL.md`, avec des liens vers cette documentation, est publiée dans [`docs/skill.md`](https://github.com/WillIsback/syntheo-desktop/blob/main/docs/skill.md).

Les compétences de contribution sous `.agents/skills` sont des procédures internes au dépôt. Elles ne font pas partie de la compétence Syntheo.
