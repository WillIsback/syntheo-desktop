---
title: "Automatisations"
description: "Exportez automatiquement chaque réunion en Markdown dans un dossier local."
---

Les automatisations exécutent une tâche répétitive à la fin d'une réunion. Dans Syntheo, la seule action disponible est l'**export Markdown vers un dossier local**. Les actions vers des services en ligne (Slack, Notion, Linear, Google Drive) ont été retirées.

Ouvrez l'onglet **« Automatisations »** depuis **Paramètres → Espace de travail → « Automatisations »**.

## Utiliser le modèle de départ

Le modèle « Exporter toutes les réunions au format Markdown » enregistre chaque réunion terminée dans un fichier Markdown local.

1. Sélectionnez-le dans la barre latérale.
2. Choisissez un dossier d'export.
3. Vérifiez le déclencheur et l'aperçu.
4. Cliquez sur « Enregistrer et activer », ou sur « Enregistrer le brouillon » pour finir plus tard.

Une fois activé, il s'exécute à la fin de chaque réunion, quand le transcript et la note sont prêts. Désactivez-le pour conserver la configuration sans l'exécuter.

## Créer un flux personnalisé

Cliquez sur **+** dans la barre latérale des automatisations.

1. Choisissez le déclencheur : « Après la disponibilité du compte rendu de la réunion » ou « Après la fin de la réunion ».
2. Ajoutez une ou plusieurs actions « Exporter la réunion au format Markdown », par exemple pour écrire dans deux dossiers différents. Les étapes s'exécutent de haut en bas.
3. Configurez chaque action.
4. Cliquez sur « Enregistrer et activer ». Tant qu'il n'est pas activé, le flux reste à l'état de brouillon.

Un flux ne peut être activé que si chaque action a un dossier et au moins une section à exporter.

Avec le déclencheur « Après la disponibilité du compte rendu de la réunion », régénérer un compte rendu met à jour le fichier déjà exporté pour cette réunion.

## Choisir le contenu exporté

Dans un flux personnalisé, chaque action d'export Markdown propose ces réglages (le modèle de départ, lui, utilise toujours les réglages par défaut) :

- Sous « Inclure », cochez « Mémo », « Résumé », « Transcript » et « Collecter les points d'action », dans la combinaison de votre choix. Au moins une section doit rester cochée.
- Laissez « Nom de fichier » vide pour utiliser la date et le titre de la réunion, ou saisissez un motif comme `{date} {title}.md`.
- « Inclure l'ID de réunion » ajoute un identifiant court au nom du fichier, pour distinguer des réunions au titre identique.

Syntheo refuse d'écraser un fichier qui appartient à une autre réunion ou qui n'a pas été créé par Syntheo. Si un export signale un conflit, changez le nom de fichier.

Ces options sont propres aux automatisations. La commande CLI `syntheo meetings export` exporte une réunion complète vers le chemin que vous indiquez, sans ces réglages.

## Vérifier l'exécution

La fiche de l'automatisation indique si elle est activée et le résultat de sa dernière exécution, avec un message court en cas d'erreur. Vérifiez alors que le dossier choisi existe toujours et qu'il est accessible en écriture.

Syntheo doit être ouvert pour exécuter une automatisation : les réunions terminées pendant que l'application est fermée ne sont pas exportées après coup.

<Note>
  Les fichiers exportés restent sur votre machine. Si vous choisissez un dossier synchronisé par un autre logiciel, c'est ce logiciel qui en transmet le contenu.
</Note>
