Le chat de Syntheo répond à vos questions sur la réunion ouverte, cherche dans vos autres réunions et vous aide à préparer le suivi. Il utilise le modèle de langage configuré sous **Paramètres → « Intelligence »**. Sans modèle connecté, le chat vous invite à « Ouvrir les paramètres de l'IA ».

## Poser une question sur la réunion ouverte

1. Ouvrez une note de réunion.
2. Ouvrez le chat (raccourci <kbd>Ctrl</kbd>+<kbd>J</kbd>, qui l'ouvre et le ferme).
3. Posez votre question ou choisissez une suggestion. La réunion ouverte est ajoutée automatiquement au contexte.

Suggestions proposées :

- Pendant une capture : « Résumez les 5 dernières minutes. », « Suggérez la prochaine question à poser. », « Listez les éléments d'action jusqu'à présent. »
- Après la réunion : « Listez les éléments d'action. », « Rédiger un e-mail de suivi. », « Trouvez les décisions clés. »
- Quand un compte rendu existe : « Raccourcissez le résumé. » et « Allongez le résumé. »

Vous pouvez aussi demander, par exemple :

- « Compare cette réunion avec la précédente revue de projet. »
- « Retrouve les réunions où nous avons parlé de la date de lancement. »

Pour répondre, le chat peut chercher dans les titres et le contenu de vos réunions, dans vos contacts et dans les documents joints à un dossier.

Les étapes de raisonnement et les outils utilisés sont regroupés dans une ligne « Activité ». Dépliez-la pour les consulter.

## Organiser vos réunions

Demandez au chat de lister vos dossiers, d'en créer un ou d'y déplacer des réunions. Par exemple : « Range mes revues de lancement dans Projets/Lancement. » Le déplacement change l'emplacement des réunions, pas leur contenu.

Si un enregistrement ou des notes ont atterri sur la mauvaise réunion, le chat peut aussi les déplacer vers une autre réunion existante, à condition que celle-ci n'ait pas encore de transcript.

## Guider le contexte

Le chat utilise automatiquement la réunion ouverte et ajoute d'autres réunions ou personnes si votre demande le nécessite. Vous pouvez aussi faire glisser une réunion dans le chat pour l'inclure dans votre prochain message.

Nommez précisément la réunion ou la personne quand plusieurs se ressemblent, ou précisez « Utilise uniquement cette réunion ». Cliquez sur « Nouveau chat » pour repartir d'une conversation vide.

## Modifications de vos notes

Le chat agit de deux façons sur vos notes :

- **Réécriture d'un compte rendu ou d'un mémo** : le chat propose un remplacement complet. Vous voyez les différences et choisissez d'appliquer ou de refuser. Rien n'est modifié sans votre accord.
- **Correction ponctuelle** (« ce n'est pas X mais Y ») : le chat remplace directement le texte exact dans le compte rendu, le titre ou le transcript.

Pour corriger vous-même un transcript ou réattribuer un locuteur, voir [Notes, comptes rendus et transcripts](/notes#corriger-un-transcript).

## Confidentialité

Le chat envoie votre question et le contexte nécessaire au serveur de modèle de langage que vous avez configuré, et à lui seul. Si ce serveur tourne sur votre machine ou sur votre réseau, ces données ne quittent pas votre infrastructure. Le chat n'effectue aucune recherche sur le web.

Voir [Données et confidentialité](/data-and-privacy).
