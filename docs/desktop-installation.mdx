Syntheo Desktop est publié pour **Linux** (AppImage et `.deb`) et **Windows** (installeur `.exe` signé et `.msi`), en x64. Les paquets macOS ne sont pas publiés pour l'instant.

Tous les paquets sont disponibles sur la page [GitHub Releases](https://github.com/WillIsback/syntheo-desktop/releases/latest).

## Choisir le bon paquet

| Plateforme | Fichier (nom stable) | Remarques |
| --- | --- | --- |
| Linux | [`Syntheo-linux-x86_64.AppImage`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-linux-x86_64.AppImage) | Portable, sans installation. Nécessite FUSE 2. |
| Linux | [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-linux-amd64.deb) | Debian, Ubuntu et dérivées. |
| Windows | [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-windows-x64-setup.exe) | Installeur signé, installation par utilisateur. |
| Windows | [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-windows-x64.msi) | Pour les déploiements gérés. |

Les liens ci-dessus pointent toujours vers la dernière version. Chaque release publie aussi les mêmes fichiers sous un nom versionné, par exemple `Syntheo_0.4.0_amd64.AppImage` ou `Syntheo_0.4.0_x64-setup.exe`.

## Linux

### Script d'installation (AppImage)

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.sh | bash
```

Le script télécharge l'AppImage de la dernière release, vérifie sa somme SHA256, l'enregistre sous `~/.local/bin/Syntheo-<version>.AppImage` et crée la commande `syntheo`. Plusieurs versions peuvent coexister.

Options utiles :

- `--version v0.4.0` installe une version précise.
- `--deb` télécharge le paquet `.deb` au lieu de l'AppImage.
- `--to <dossier>` change le dossier d'installation (par défaut `~/.local/bin`).

Si `~/.local/bin` n'est pas dans votre `PATH`, le script vous indique la ligne à ajouter.

Sur les distributions basées sur Arch (Omarchy, EndeavourOS, Manjaro), l'AppImage a besoin de FUSE 2 :

```bash
sudo pacman -S fuse2
```

### Debian et Ubuntu

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.sh | bash -s -- --deb
sudo apt install ~/.local/bin/Syntheo_*_amd64.deb
```

Vous pouvez aussi télécharger [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-linux-amd64.deb) et l'installer avec `sudo apt install ./Syntheo-linux-amd64.deb`.

### AppImage téléchargée à la main

```bash
chmod +x ./Syntheo-linux-x86_64.AppImage
./Syntheo-linux-x86_64.AppImage
```

### Fenêtre noire sous Wayland

Syntheo désactive déjà le rendu DMA-BUF de WebKitGTK au démarrage, ce qui corrige la plupart des fenêtres vides (notamment NVIDIA sous Wayland). Si la fenêtre reste noire, désactivez aussi la composition :

```bash
WEBKIT_DISABLE_COMPOSITING_MODE=1 syntheo
```

## Windows

### Installeur

Téléchargez [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-windows-x64-setup.exe), puis lancez-le. L'installation se fait dans votre profil utilisateur, sans droits administrateur.

L'installeur et le `.msi` sont **signés** (Azure Artifact Signing) : Windows les attribue à **William Derue**. SmartScreen peut encore afficher un avertissement sur les premières versions, le temps que la réputation du binaire se construise.

### Script d'installation (PowerShell)

```powershell
irm https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.ps1 | iex
```

Le script télécharge l'installeur de la dernière release, vérifie sa somme SHA256 avec `SHA256SUMS-windows` et l'installe en mode silencieux (par utilisateur, sans élévation). Pour une version précise :

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.ps1))) -Version v0.4.0
```

### MSI

Téléchargez [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/syntheo-desktop/releases/latest/download/Syntheo-windows-x64.msi) pour une installation gérée (GPO, Intune, etc.).

## Vérifier un paquet

Chaque release publie `SHA256SUMS` (tous les paquets) et `SHA256SUMS-windows`, ainsi qu'une attestation de provenance GitHub.

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify Syntheo-linux-x86_64.AppImage -R WillIsback/syntheo-desktop
```

Sous Windows, comparez le résultat de `Get-FileHash <fichier>` avec la ligne correspondante de `SHA256SUMS-windows`.

## Mettre à jour

Syntheo n'intègre pas de mise à jour automatique. Pour passer à une nouvelle version, relancez le script d'installation ou téléchargez le nouveau paquet depuis [GitHub Releases](https://github.com/WillIsback/syntheo-desktop/releases/latest). Vos notes sont conservées.

## macOS

Les paquets macOS ne sont pas publiés pour l'instant. Pour compiler l'application vous-même, suivez [Construire depuis les sources](https://github.com/WillIsback/syntheo-desktop/blob/main/CONTRIBUTING.md#construire-depuis-les-sources) dans `CONTRIBUTING.md`.
