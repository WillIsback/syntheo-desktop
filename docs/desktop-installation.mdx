Syntheo Desktop is currently distributed for **Linux** (AppImage and DEB). Windows and macOS packages are not published yet.

## Choose the right build

| Platform | Build | Notes |
| --- | --- | --- |
| Linux | AppImage (x64) | Portable build. Needs FUSE 2. |
| Linux | DEB (x64) | For Debian, Ubuntu, and compatible distributions. |

## Linux

### One-line installer (AppImage)

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.sh | bash
```

The script downloads the latest release's AppImage to `~/.local/bin`, verifies its SHA256, saves it as `Syntheo-<version>.AppImage`, and creates a `syntheo` command. To install a specific published version:

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.sh | bash -s -- --version v0.1.1
```

On Arch-based distributions (Omarchy, EndeavourOS, Manjaro), the AppImage requires FUSE 2:

```bash
sudo pacman -S fuse2
```

### Debian and Ubuntu

The same script can download the `.deb` instead:

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/syntheo-desktop/main/scripts/install.sh | bash -s -- --deb
sudo apt install ~/.local/bin/Syntheo_*_amd64.deb
```

### AppImage

Download an AppImage from the [releases page](https://github.com/WillIsback/syntheo-desktop/releases), make it executable, and open it:

```bash
chmod +x ./Syntheo-*.AppImage
./Syntheo-*.AppImage
```

On Wayland with an NVIDIA GPU, if the window is black or only audio plays, launch with:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 ./Syntheo-*.AppImage
```

If the window is still black, also disable compositing:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 ./Syntheo-*.AppImage
```

## macOS and Windows

Packages are not published yet. To build the app on any platform, follow [Construire depuis les sources](https://github.com/WillIsback/syntheo-desktop/blob/main/CONTRIBUTING.md#construire-depuis-les-sources) in `CONTRIBUTING.md`.

## Data and privacy

Syntheo runs transcription and summaries only against the on-premise endpoints you configure, and never keeps audio. See [Data and privacy](/data-and-privacy).

When installation is complete, continue to [Your first meeting](/quickstart). If the app does not open or cannot capture audio, see [Troubleshooting](/troubleshooting).
