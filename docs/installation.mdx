## Current availability

The `syntheo` executable includes both the CLI and the local MCP server.

<Warning>
  Homebrew, standalone release binaries, and Windows package-manager distribution are forthcoming. Do not rely on those channels yet.
</Warning>

## Install from the desktop app

Open **Settings → Developers** and select **Install** (or **Reinstall**). Direct-download desktop builds copy the bundled CLI onto your PATH.

| Platform | Installed command | Path |
| --- | --- | --- |
| macOS | `syntheo` | `~/.local/bin/syntheo` |
| Linux (DEB / AppImage) | `syntheo` | `~/.local/bin/syntheo` |
| Windows | `syntheo` | `%LOCALAPPDATA%\Syntheo\bin\syntheo.exe` (added to your user PATH) |

On macOS and Linux, add `~/.local/bin` to `PATH` if your shell cannot find `syntheo`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

On Windows, open a new terminal after installing so the PATH update applies.

<Note>
  The Mac App Store build does not include bundled CLI installation. Use [build from source](#build-from-source) instead.
</Note>

## Build from source

To build the CLI yourself instead:

```bash
git clone https://github.com/WillIsback/syntheo-desktop.git
cd syntheo
cargo install --locked --path apps/cli
syntheo --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `syntheo`.

## Connect to local data

By default, the CLI looks for `syntheo/app.db` in your operating system's application-data directory. It also recognizes legacy Syntheo locations.

Open the desktop app once so it can create the database. After that, the CLI and local MCP server work while the app is closed.

For a custom database location, pass a global option or environment variable:

```bash
syntheo --db-path /path/to/app.db --json meetings list
SYNTHEO_DB_PATH=/path/to/app.db syntheo --json meetings list
```

If you have an Syntheo data directory containing `app.db`, use:

```bash
syntheo --base /path/to/syntheo-data --json meetings list
```

The CLI opens the database in read-only query mode for meeting reads. Proposal create and decline commands, and `syntheo mcp`, open the same file for writes so they can stage or discard pending edits. They do not create a database or run migrations.
