Chaque note de réunion propose jusqu'à trois vues :

- **« Mémos »** : les notes que vous écrivez vous-même.
- **Le compte rendu** : la note structurée générée par votre modèle de langage. Son onglet porte le nom du modèle de compte rendu utilisé.
- **« Transcript »** : la conversation transcrite.

Vous modifiez les mémos et les comptes rendus comme des notes ordinaires.

<Note>
  Syntheo ne conserve jamais l'audio. Il n'y a donc ni lecteur audio, ni retranscription après coup : le transcript produit pendant la capture est la seule trace de la conversation.
</Note>

## Vérifier une modification proposée

Quand le chat, la CLI ou le serveur MCP local propose de remplacer un mémo ou un compte rendu, la note affiche un bandeau « 1 modification en attente ». Choisissez « Vérifier la note » ou « Vérifier le compte rendu » pour voir les différences, puis appliquez ou refusez la proposition. Tant que vous ne l'appliquez pas, la note reste inchangée.

## Corriger un transcript

- Une fois la capture arrêtée, cliquez à nouveau sur l'onglet « Transcript » (icône crayon) pour passer en mode édition. Cliquez encore une fois pour revenir à la lecture.
- Sélectionnez des mots pour afficher un menu : « Modifier », « Modifier l'orateur depuis ici » ou « Copier ».
- Sélectionnez plusieurs blocs pour les réattribuer d'un coup avec « Modifier l'orateur », les « Fusionner » ou les « Supprimer » (en mode édition).
- Cliquez sur le nom d'un locuteur pour choisir un participant existant ou « Créer un nouvel intervenant ». Cochez « Appliquer à tout » pour mettre à jour tous les segments de ce locuteur.
- Faites un clic droit sur l'onglet « Transcript » pour copier tout le transcript ou reprendre l'écoute.

## Choisir la forme du compte rendu

Cliquez sur l'onglet du compte rendu pour ouvrir le sélecteur de modèles. Choisissez « Auto » ou un modèle, ou utilisez « Régénérer » sur le modèle déjà utilisé.

Consultez [Personnaliser les comptes rendus](/customize-summaries) pour créer vos propres modèles.

## Compléter une note existante

Faites un clic droit sur l'onglet « Transcript » et choisissez « Reprendre l'écoute » pour ajouter une nouvelle capture à la même note. C'est utile quand une réunion reprend après une pause.

Vous pouvez aussi importer un fichier audio ou un transcript depuis le menu **•••** de la note (« Téléverser un audio », « Téléverser un transcript »). Voir [Importer des enregistrements](/import-recordings).

## Exporter une réunion

1. Ouvrez le menu **•••** dans l'en-tête de la note.
2. Choisissez « Exporter ».
3. Sous « Format de fichier », choisissez PDF, TXT, Markdown ou Org.
4. Sous « Inclure », cochez le mémo, le résumé et le transcript, dans la combinaison de votre choix.

Syntheo écrit le fichier dans votre dossier d'export, puis l'affiche dans le gestionnaire de fichiers. Par défaut, il s'agit de votre dossier Téléchargements. Changez-le sous **Paramètres → Général → « Emplacement d'export »**.

Pour exporter automatiquement chaque réunion en Markdown, voir [Automatisations](/automations). La CLI exporte aussi une réunion en Markdown ou en JSON (`syntheo meetings export`).

Syntheo ne propose aucun partage en ligne : pour transmettre une réunion, exportez-la puis envoyez le fichier par le moyen de votre choix.

## Consulter vos statistiques

Ouvrez **Paramètres → « Analyses »** pour voir :

- un aperçu : nombre de conversations, heures transcrites, jours actifs ;
- votre activité au cours de l'année écoulée et votre série hebdomadaire ;
- vos habitudes (jour le plus chargé, durée typique d'une conversation) sur 7 jours, 30 jours ou depuis toujours ;
- vos badges, attribués à certaines étapes (première conversation, 10 conversations, etc.). Ils restent sur cet appareil, même si vous supprimez une note.

Ces statistiques sont calculées localement et ne sont disponibles que dans l'application de bureau.
