---
title: "Erreurs et codes de sortie"
description: "Interprétez les échecs de la CLI et du MCP, et corrigez-les sans toucher au stockage de Syntheo."
---

Sans `--json`, la CLI écrit ses erreurs sur la sortie d'erreur, en texte lisible commençant par `error:`. Avec `--json`, elle écrit sur la sortie d'erreur un objet contenant `schema_version` et `error`, lui-même composé de `code`, `message` et `exit_code`.

```json
{
  "schema_version": "1",
  "error": {
    "code": "not_found",
    "message": "meeting 'abc' not found",
    "exit_code": 2
  }
}
```

## Codes de sortie

| Code de sortie | `code` JSON | Signification | Que faire |
| --- | --- | --- | --- |
| `0` | — | Succès | Lisez la sortie standard. |
| `1` | `operation_failed` | Échec d'ouverture de la base, de validation ou d'opération ; ou rapport `doctor` avec `ready` à `false` ; ou import terminé en `failed` | Lisez le message. Pour `doctor`, inspectez le rapport JSON et vérifiez que l'application et la CLI ont des versions compatibles. |
| `2` | `not_found` | Réunion, note, proposition ou autre donnée introuvable | Relancez une liste et utilisez un identifiant renvoyé. |
| `3` | `database_not_found` | Fichier de base introuvable | Ouvrez Syntheo une fois pour créer la base, ou indiquez le bon chemin avec `--db-path` ou `--base`. |
| `4` | `output_exists` | Le fichier d'export existe déjà | Choisissez un autre chemin, ou passez explicitement `--force` pour le remplacer. |

Deux cas particuliers réutilisent le code 2 :

- **Arguments invalides** : le code JSON est `invalid_arguments`, avec le code de sortie de Clap (2 en général).
- **`meetings import --wait`** : si l'attente expire avant la fin, la CLI renvoie 2 sans objet d'erreur. La tâche continue ; suivez-la avec `meetings import-status`.

## Messages fréquents

| Message | Cause | Que faire |
| --- | --- | --- |
| `base Syntheo introuvable à … ; lancez Syntheo une fois ou passez --db-path` | Aucune base à l'emplacement retenu | Ouvrez l'application, ou passez `--db-path`. |
| `Open the updated Syntheo desktop app before importing recordings` | Import demandé alors que l'application n'est pas ouverte | Ouvrez l'application sur la même base, puis relancez l'import avec la même `--request-key`. |
| `Unsupported recording format` | Extension non prise en charge | Utilisez WAV, MP3, OGG, MP4, M4A, FLAC, WebM ou AAC. |
| `Folder does not exist; use meetings folders to choose an existing folder` | Dossier inconnu | Choisissez un chemin renvoyé par `meetings folders`. |

## Erreurs MCP

Le serveur MCP signale une réunion, une proposition ou un import introuvable comme « paramètres invalides ». Les échecs de validation et les conflits (contenu de proposition vide, plusieurs résumés sans `target_id`, refus d'une proposition qui n'est plus en attente) sont signalés comme erreurs internes, tout comme les échecs de base de données et de sérialisation.

<Warning>
  Ne tentez jamais de réparer en créant des tables, en lançant des migrations ou en exécutant du SQL. L'application gère seule l'initialisation et les migrations du schéma ; une modification manuelle peut corrompre la base.
</Warning>
