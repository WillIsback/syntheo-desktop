Syntheo est en construction (bêta). Cette page liste les chantiers prévus, sans engagement de date. L'état actuel du produit est décrit dans [Architecture](/architecture).

Quelle que soit la forme du produit, les principes restent les mêmes : inférence uniquement sur les serveurs que vous choisissez, aucun audio conservé, ni compte imposé, ni télémétrie.

## Chantiers prévus

<Steps>
  <Step title="CLI">
    Une interface en ligne de commande distribuée avec l'application, pour consulter et exploiter vos réunions depuis un terminal ou un agent. Aujourd'hui, la CLI se compile depuis les sources : voir [Installer la CLI](/installation).
  </Step>
  <Step title="API REST">
    Une API REST pour intégrer Syntheo à vos outils et automatisations.
  </Step>
  <Step title="Version mobile">
    Une application mobile.
  </Step>
  <Step title="Version web">
    Une version utilisable depuis un navigateur.
  </Step>
</Steps>

## Proposer une idée

Les suggestions et les signalements se font dans les [issues GitHub](https://github.com/WillIsback/syntheo-desktop/issues).
