# Internationalisation français d'abord — plan d'implémentation (lot 07)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** L'application s'affiche en **français** par défaut et dispose d'un catalogue `fr` complet ; le dépôt ne conserve que les catalogues `en` (source) et `fr`.

**Architecture:** Lingui 6 avec catalogs au format PO (`@lingui/format-po`), source `en`, 109 locales aujourd'hui. On réduit la configuration à `en` + `fr` (suppression des 107 autres dossiers), on force la locale d'affichage en `fr`, puis on remplit `fr/messages.po` (~965 chaînes, dont 952 vides) via un **script batch** qui interroge l'endpoint LLM OpenAI-compatible **configuré par l'utilisateur** (vLLM du DGX), avec un glossaire. Les `msgstr` sont réinjectés dans le PO, puis compilés.

**Tech Stack:** Lingui 6 (`@lingui/cli`, `@lingui/format-po`), Node 22 (`node --test`), TypeScript/React 19, Vitest, pnpm 11.

**Spec:** `docs/superpowers/specs/2026-10-24-syntheo-desktop-migration-design.md` (chantier « i18n: fr », Phase 3). Dépend du lot 06b (rebrand : `Syntheo` dans les msgids).

## Global Constraints

- **Aucun provider cloud** : le script ne parle qu'à l'endpoint OpenAI-compatible fourni (`SYNTHEO_I18N_BASE_URL`), jamais à un service tiers.
- Le catalogue `fr` est la seule cible traduite ; `en` reste la source (`SOURCE_LOCALE = "en"`).
- Textes d'interface **en français d'abord** : la locale d'affichage par défaut est `fr`.
- Les msgids sont en anglais et portent désormais « Syntheo » (lot 06b) : la traduction FR écrit « Syntheo ».
- `pnpm exec dprint fmt` (global) avant de pousser.
- Un commit Conventional Commits par tâche ; PR avec `Closes #N` et `[skip release]`.
- Rappel : `pnpm -F @syntheo/desktop i18n:extract` / `i18n:compile` / `i18n:check` existent déjà.

## Review Focus

- Aucune locale autre que `en`/`fr` ne subsiste → `ls apps/desktop/src/i18n/locales` = `en fr` ; `SUPPORTED_DISPLAY_LOCALES` = `["en","fr"]`.
- Une machine neuve démarre **en français** (aucun réglage) → test `resolveDisplayLocale(null)` = `"fr"`.
- Un utilisateur qui choisit l'anglais (`ai_language` = `en`) garde l'UI anglaise → test `resolveDisplayLocale("en")` = `"en"`.
- Le script n'exige pas d'endpoint joignable en CI → test avec un `fetch` simulé (Task 3).
- `fr/messages.po` sans `msgstr ""` vide (hors en-tête) après la traduction → vérification en Task 4.

export function resolveDisplayLocale(
  language: string | null | undefined,
): DisplayLocale {
  if (language) {
    try {
      const locale = new Intl.Locale(language);
      const exact = locale.toString();
      if (supportedDisplayLocales.has(exact)) {
        return exact as DisplayLocale;
      }
      const base = supportedDisplayLocaleByLanguage.get(locale.language);
      if (base) {
        return base;
      }
      if (locale.language === "en") {
        return "en";
      }
    } catch {
      // langue invalide : on retombe sur le français
    }
  }
  return "fr";
}

- [ ] **Step 3: Implémenter**

Créer `scripts/i18n-translate.mjs` :

- Lit le PO source avec `formatter` de `@lingui/format-po` (`import { formatter } from "@lingui/format-po"`), extrait les entrées `(msgid, msgstr)`.
- Ne traduit que les entrées dont `msgid` n'est pas vide et dont le `msgstr` cible est vide.
- Découpe en lots (`--batch-size`, défaut 20) et appelle `POST {BASE_URL}/chat/completions` (`model`, `messages`, `temperature: 0`, `response_format: { type: "json_object" }`) avec :

```js
export const SYSTEM_PROMPT = `Tu traduis des chaînes d'interface logicielle en français.
Règles :
- Traduis uniquement le texte, conserve les variables {0} {1} {title}, le balisage et la ponctuation.
- Utilise le vouvoiement, un ton sobre et professionnel.
- Glossaire imposé : note = note, compte rendu = compte rendu, modèle = modèle, réunion = réunion.
- Réponds STRICTEMENT par un objet JSON {"0": "...", "1": "..."} indexé par l'ordre des chaînes fournies.`;

export function buildTranslationPrompt(strings, glossary = {}) {
  return `${SYSTEM_PROMPT}\n\nGlossaire additionnel : ${JSON.stringify(glossary)}\n\nChaînes à traduire : ${JSON.stringify(strings)}`;
}

export function parseTranslations(raw, expected) {
  const parsed = JSON.parse(raw);
  const out = [];
  for (let i = 0; i < expected; i += 1) {
    if (typeof parsed[String(i)] !== "string") {
      throw new Error(`traduction manquante à l'index ${i}`);
    }
    out.push(parsed[String(i)]);
  }
  return out;
}
```

- Réinjecte les `msgstr` et réécrit le PO cible avec le même formatter (structure et `#:` commentaires préservés).
- CLI : options `--source` (défaut `apps/desktop/src/i18n/locales/en/messages.po`), `--target` (défaut `.../fr/messages.po`), `--batch-size`, `--dry-run`.
